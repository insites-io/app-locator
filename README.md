## Overview

The Insites Locator provides a basic scaffold for a locations database and geojson lookup functionality.
&nbsp;
&nbsp;
&nbsp;

## Features
- Multi-location database
- Geojson lookup
- Google Map API integration
- Locator Module integration

## Pre-requisite Modules
Please make sure to install these modules from the Console before you install it on your instance.

- Core Module
- Databases Module
- CMS Module
- **Client Portal App**
- **Locator Module**
